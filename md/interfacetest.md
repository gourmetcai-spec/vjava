Using the following template (interfacetest.pdf) create a interface test plan that covers all the user interfaces and features of your program.

The following is an example of the information to go into each column:

Test Scenario: Descriptive test name (one to two words is fine)
Test Case: Some type of numbering system (ex. 1)
Pre-Condition: Any variables that have to be set / initialized / inputted and/or events that need to occur before this method is executed.
Test Steps: Steps to follow to test the method.
Test Data: Provide sample data to test the method.
Expected Result: What should happen, what value should be returned, what should be outputted, etc.
