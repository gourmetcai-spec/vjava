Your game must have a computer player that is programmed with a strategy. A strategy is simply what the computer player will do given a particular situation. This is called Intelligent Software which is defined as: An application that uses artificial intelligence to analyze and interpret data, or communicate with systems and humans.

NOTE: If your game only has one player the human player has a choice to play as a human or have the computer player play. If your game has two or more players, then at least one of the players should be a computer player and/or the human player can choose one of the players to be a computer player.

Requirements

The following parts of the code must be documented to highlight the following:

COMPUTER PLAYER - DIFFICULTY: Computer player has 2 or more difficulty levels. Difficulty levels are chosen by the human player. There must be a discernable difference between the two or more difficulty levels.
COMPUTER PLAYER - STRATEGY: Computer player uses strategy or randomness properly, with clear and appropriate logic. In your code document about what strategies and/or randomness the computer player is using. Also, document which difficulty level a particular strategy or randomness is, and what makes it that difficulty level.
COMPUTER PLAYER - MOVES: The Computer player is able to make moves without human player input. Document in your code where this occurs.
COMPUTER PLAYER - EXECUTION: The Computer player is triggered at the correct time in the game loop. Document where the computer player code is run. This also needs to be evident when playing the game.
Documentation

To allow me to easily find your computer player documentation start the comment with COMPUTER PLAYER - CONCEPT.
